# PATHAI UI Components

Modular components following FRONTEND_SPEC.md:
- `ConsentCheckbox.tsx`: Privacy and terms consent checkbox (disables confirmation until checked)
- `Question.tsx`: Question renderer supporting single, multi, and text question types
- `OptionList.tsx`: Single/multi option list supporting exclusive choices, limits, and "other" text inputs
- `ProgressTracker.tsx`: Progress status indicator displaying "ຄຳຖາມ n/28" and autosave notice
- `SubmitConfirm.tsx`: Incomplete answers confirmation modal
- `ErrorBanner.tsx`: Standard error banner with retry callback
- `Loading.tsx`: Pulse loading skeleton
