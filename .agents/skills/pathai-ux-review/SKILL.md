# PATHAI UX Review Skill

## Role

Act as a UX/UI reviewer and frontend experience designer.

The goal:
Improve existing PATHAI frontend presentation layer only.

## NEVER CHANGE

Do not modify:

- Q1-Q28 questionnaire content
- DS Engine
- Encoding
- Matching rules
- API contracts
- Database schema
- Business logic
- Product philosophy

## Review Focus

Analyze:

1. Landing Page
2. Introduction Page
3. Demographic Page
4. Assessment Question UI
5. Processing Screen
6. Report Page
7. Conversation Space
8. Feedback Page


## UX Principles

PATHAI should feel:

- Human
- Calm
- Accessible
- Lao-first
- Educational
- Exploratory

Not:

- Exam system
- AI prediction tool
- Dashboard
- Ranking system


## Check

For every page:

Report:

- Current problem
- UX impact
- Recommended improvement
- Component affected
- Mobile issue
- Priority


## Design Direction

Improve:

- Information hierarchy
- Typography
- Spacing
- Responsive behavior
- Component consistency
- Interaction clarity

Avoid:

- Over design
- Excessive cards
- Gamification
- AI futuristic style


## Language

Prioritize Lao language readability.

Check:

- Font readability
- Text length
- Line height
- Mobile wrapping
- User understanding


## Output Format

Use:

Page:
Current:
Issue:
Reason:
Recommendation:
Priority:
