## 1. ບົດຄັດຫຍໍ້

PATHAI v4.0 ສະເໜີໃຫ້ວັດຄວາມສົນໃຈອາຊີບ 7 ສາຍ (C1–C7) ໂດຍອີງກັບ Holland/RIASEC, profile correlation, career experiments, skill bridge ແລະ parent conversation. ຈຸດປະສົງຄືໃຫ້ຜົນເປັນ “ທິດທາງເພື່ອສຳຫຼວດ” ບໍ່ແມ່ນຄຳຕັດສິນອາຊີບຖາວອນ.

## 5. ສູດຄຳນວນທີ່ສະເໜີ

### 5.1 Profile score

`S_c = Σ(weight of each selected option for career line c)`

ສຳລັບຄຳຖາມປະສົບການຈິງ Q29/Q30 ຮ່າງເສະເໜີນ້ຳໜັກ `× 1.5`.

### 5.2 Profile correlation

`r_c = corr([S1…S7], [T_c1…T_c7])`  ແລະ `c_max = argmax(r_c)`

ການແປຜົນທີ່ສະເໜີ:

| r_max | ຊື່ຮູບແບບ | ຄວາມໝາຍ |
|---:|---|---|
| ≥ 0.80 | Laser Focus | ທິດທາງດຽວຊັດເຈນ |
| 0.60–0.79 | Clear Direction | ມີສາຍຫຼັກຊັດ |
| 0.40–0.59 | Dual Interest | ມີ 2 ສາຍທີ່ຄວນທົດລອງ |
| < 0.40 | Multi-Scattered | ຄວນສຳຫຼວດເພີ່ມ |

### 5.3 Career Experiment Score

`CE_c = number of completed experiments in c / 7`

ຄ່າ `≥ 0.5` ຖືວ່າມີຫຼັກຖານຈາກການລອງເຮັດ; ຕ່ຳກວ່ານັ້ນໃຫ້ແນະນຳ micro-experiment ເພີ່ມ.

### 5.4 Strategy / Risk / Family adjustment

- `S_adjusted = S_c × (1 + α)` ໂດຍ `α` ຈາກ family context — ຕ້ອງກວດສອບ bias ກ່ອນໃຊ້ຈິງ
- Strategy ແບ່ງເປັນ Straight Path, Flexible Path, Pivot Ready, Need Support
- Risk tolerance ສະເໜີໃຫ້ໃຊ້ຈຳນວນທາງເລືອກ/ຄວາມປອດໄພຈາກ Q28; ຕ້ອງກຳນົດທິດທາງຄະແນນໃໝ່ໃຫ້ຊັດກ່ອນ release

## 8. Parent Conversation Guide

1. ກຽມຕົວ: ຂຽນຄວາມສົນໃຈ, ກຽມຂໍ້ມູນ, ເລືອກເວລາຄຸຍ
2. ເລີ່ມຄຸຍ: ຂອບໃຈພໍ່ແມ່, ບອກຄວາມຮູ້ສຶກ, ບອກວ່າຄິດມາແລ້ວ
3. ນຳສະເໜີ: ສະແດງຜົນ, ຄຸຍເລື່ອງການເງິນ, ຂໍຄວາມຄິດເຫັນ
4. ຮັບມືຄຳຕອບ: ຟັງ, ຖາມ, ສະເໜີແຜນນ້ອຍ, ແລະພັກການຄຸຍຖ້າອາລົມຮ້ອນ
5. ຕິດຕາມ: ນັດຄຸຍອີກ, ລາຍງານຄວາມຄືບໜ້າ, ຂໍຄຳແນະນຳເພີ່ມ

## 9. Validation plan ກ່ອນເປີດໃຊ້

- Content validity: IOC ≥ 0.5 ຕາມເກນທີ່ອາຈານຮັບຮອງ
- Construct validity: KMO ≥ 0.60, factor loading ≥ 0.40
- Reliability: Cronbach's alpha ≥ 0.70 ຕາມມິຕິທີ່ເໝາະສົມ
- ตรวจความสอดคล้องของ Lao/English wording และ option code
- ທົດສອບກັບກຸ່ມນຳຮ່ອງ, ກວດ bias ຂອງ family adjustment ແລະ ບໍ່ໃຫ້ຜົນຖືກອ່ານເປັນການວິນິດໄສ
