# PATHAI Types

Domain and contract types following the PATHAI Specification:
- `form.ts`: Questionnaire structures (`QuestionnaireForm`, `FormItem`, `FormOption`, `DraftAnswer`, `DraftAnswers`)
- `session.ts`: Session lifecycle payloads (`SessionResponse`, `SessionStatus`)
- `report.ts`: Result schemas (`ReportPattern`, `ReportPath`, `ReportResponse`)
- `feedback.ts`: User reflection and feedback payloads (`FeedbackAgreement`, `FeedbackPayload`)
